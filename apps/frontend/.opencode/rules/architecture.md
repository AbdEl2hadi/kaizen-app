

## Source Layout (`src/`)

```
src/
├── router.tsx                     # Router factory + QueryClient context
├── routeTree.gen.ts               # AUTO-GENERATED by `tsr generate` — do not edit
├── styles.css                     # Tailwind entry + design tokens
├── routes/                        # FILE-BASED ROUTES (TanStack Router)
│   ├── __root.tsx                 # Root layout: <html>, global providers, devtools
│   ├── index.tsx                  # Home page
│   ├── (..public routes)          # public routes
│   ├── _layout.tsx                # Layout groups (`_` prefix) with <Outlet /> (for example _auth (guarded routes))
│   └── _layout/
│       └── ... guarded/paginated routes
├── components/                    # Presentational components
│   ├── ui/                        # shadcn/ui primitives (button, input, dialog...)
│   ├── shared/                    # Reusable cross-feature components
│   ├── layout/                    # App shell pieces (sidebar, topbar, nav)
│   └── <page>/                    # Page-specific sections
├── features/                      # FEATURE-SCOPED modules (domain code)
│   └── <feature>/
│       ├── api/                   # Query options + mutation hooks
│       ├── hooks/                 # Form/logic hooks
│       ├── schema/                # zod schemas shared with forms
│       ├── components/            # Feature-specific components (optional)
│       ├── guard.ts               # Route guards (if the feature gates routes)
│       └── types.ts               # Feature types
├── integrations/                  # Third-party library wiring (one folder per lib)
│   └── <library>/
│       ├── root-provider.tsx      # Provider/context factory
│       └── devtools.tsx
├── providers/                     # App-wide context providers
├── hooks/                         # Cross-feature shared hooks
├── lib/                           # Cross-cutting, dependency-free helpers
│   ├── api.ts                     # HTTP client instance + response types
│   ├── env.ts                     # Validated env access
│   └── utils.ts                   # cn() and other helpers
├── constants/                     # Static config values, query-key factories
├── types/                         # App-wide types shared across features
└── public/                        # Static assets (logos, images, icons)
```
